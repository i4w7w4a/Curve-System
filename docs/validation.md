## Что проверка не покрывает

Полный прогон интерактивного интерфейса в настоящем браузере, проверка на мобильных устройствах и browser accessibility audit для этой сборки **не завершены**: доступная среда не позволила открыть локальную лабораторию. Проверка логики в DOM harness не заменяет проверку отображения и событий в браузере.

After Effects, Blender, Unity, Godot и прочие среды не запускались. Примеры и предлагаемые адаптеры не объявляются испытанными интеграциями. Все 22 исследованных сторонних проекта не устанавливались: обзор основан на документации, исходниках и доступных лицензиях.

Численные тесты и независимый review существенно снижают риск, но не являются формальным доказательством для всего непрерывного пространства параметров. Перед использованием в управлении реальным оборудованием требуется отдельная проверка требований конкретной системы.

## Воспроизвести основные проверки

```sh
npm run check
```

Команда запускает математические тесты, проверяет локальные ссылки и сравнивает генерируемые артефакты. Внешний браузер, Python JSON Schema validator и однократный DOM harness не входят в эту команду.

Следующая ручная проверка: открыть [Curve Lab](../examples/playground.html) через HTTP-сервер, сравнить desktop/mobile, проверить slider/keyboard controls, воспроизведение, поиск и экспорт. При выявлении проблемы приложить id, параметры, браузер, размеры окна и конкретное наблюдение.
