# Как использовать кривые

Это руководство относится к reference implementation 0.1. Полный математический разбор — в [справочнике](mathematics.md); карточки и параметры — в [атласе](catalog.md).

## 1. Выбрать характер и проверить движение

Запустить из корня репозитория:

```sh
python3 -m http.server 8000
```

Открыть `http://localhost:8000/examples/playground.html`. В левой колонке выбрать пресет, справа настроить параметры. В поле «Сравнить» задать вторую кривую. Пунктирный график и маленькая серая точка относятся к сравнению. Обе кривые получают одинаковое нормализованное время.

Начать удобно с `linear`, `sine-in-out`, `smootherstep` и `back-out`: они показывают четыре хорошо различимых режима. Двигать ползунок времени, затем включить воспроизведение. Для сравнения ощущений держать одинаковыми расстояние, длительность и объект.

Параметры сравниваемой кривой в этой версии берутся по умолчанию; произвольное сравнение двух независимо настроенных наборов — следующий шаг. Это лаборатория одного перехода, а не timeline-editor.

### Пружины и два разных времени

У `spring-response` и `spring-ease` параметр «Горизонт T» задаёт физическое окно отклика. Поле «Длительность» под просмотрщиком задаёт скорость проигрывания этого окна. Например, `T=1` и просмотр за 2 секунды замедляют физический отклик вдвое. Чтобы наблюдать исходную физическую скорость модели, выставить одинаковые значения.

`spring-response` может завершить окно выше или ниже 1. `spring-ease` масштабирует значение так, чтобы конец был равен 1, но не гарантирует нулевую конечную скорость. Остановка маркера на конце окна показывает окончание проигрывания, а не доказательство, что пружина естественно остановилась.

## 2. Применить скалярную кривую в JavaScript

```js
import { evaluate } from './src/curves.mjs';

const startSeconds = 10;
const durationSeconds = 2;
const from = 100;
const to = 500;

function positionAt(seconds) {
  // Явная политика приложения: держать крайнее значение за границей.
  const t = Math.min(1, Math.max(0, (seconds - startSeconds) / durationSeconds));
  return from + (to - from) * evaluate('smootherstep', t);
}
```

Clamp времени здесь — осознанный выбор приложения. В ядре время вне `[0,1]` отклоняется. Для `smootherstep` такое продолжение сохраняет непрерывность положения, скорости и ускорения, но рывок в точках соединения меняется скачком. Для `linear` уже скорость скачет при запуске и остановке.

Для `back-out` сохранять выход за диапазон:

```js
const f = evaluate('back-out', 0.7, { overshoot: 1.5 });
const x = from + (to - from) * f;
```

Обрезать `f` до 1 означает убрать часть движения и создать новое место изменения производных. Если свойство не допускает overshoot, лучше выбрать ограниченную монотонную кривую. Для opacity диапазон обычно ограничивается средой; итоговая форма поэтому может отличаться от нарисованного исходного easing.

## 3. Получить реальные скорость и ускорение

```js
import { derivatives } from './src/curves.mjs';

const t = 0.5;
const d = derivatives('smootherstep', t);
const delta = 400; // px
const T = 2;      // s

const velocity = d.velocity === null ? null : delta * d.velocity / T;
const acceleration = d.acceleration === null ? null : delta * d.acceleration / T ** 2;
const jerk = d.jerk === null ? null : delta * d.jerk / T ** 3;
// Здесь velocity = 375 px/s, acceleration = 0 px/s², jerk = -1500 px/s³.
```

Скалярная производная может быть отрицательной. Для пространственного движения скорость в смысле speed — модуль вектора; значение одного канала Position X не сообщает полную скорость по изогнутой траектории. Для построения движения по пути нужны его геометрия и, при необходимости, параметризация длиной дуги. [Adobe: temporal/spatial interpolation](https://helpx.adobe.com/after-effects/desktop/animate-in-after-effects/animation-keyframes/keyframe-interpolation.html).

## 4. Кубическая Bézier

```js
const bezier = { x1: 0.22, y1: 0, x2: 0.36, y2: 1 };
const progress = evaluate('cubic-bezier', 0.4, bezier);
```

Временная Bézier сначала решает `Bx(u)=t`, затем вычисляет `By(u)`. Обычное вычисление `By(t)` описывает другую функцию. `x1` и `x2` находятся в `[0,1]`; в редакторе 0.1 `y1` и `y2` ограничены `[-2,3]`, хотя CSS разрешает произвольные конечные y. Это ограничение нашего интерфейса, а не стандарта. [W3C CSS Easing](https://www.w3.org/TR/css-easing-1/).

Крайний наклон обычно равен `y1/x1` и `(1-y2)/(1-x2)`, но при нулевом знаменателе нужен анализ более высоких порядков. Сохранение нулевых значений на концах не гарантирует нулевую скорость.

## 5. Экспорт в CSS

```js
import { toCSS } from './src/curves.mjs';
console.log(toCSS('cubic-bezier', { x1: 0.22, y1: 0, x2: 0.36, y2: 1 }));
// cubic-bezier(0.22, 0, 0.36, 1)
```

```css
.card {
  transition: transform 600ms cubic-bezier(0.22, 0, 0.36, 1);
}

@media (prefers-reduced-motion: reduce) {
  .card { transition: none; }
}
```

В этой версии точный экспорт есть у `linear`, `cubic-bezier`, `smoothstep` и двух `steps`. Для остальных `toCSS` возвращает `null`. Это не означает, что их невозможно воспроизвести в CSS: сложную кривую можно аппроксимировать `linear()` или keyframes. Такой экспорт с измеряемой ошибкой ещё не реализован. [CSS Easing Level 2](https://www.w3.org/TR/css-easing-2/), [Chrome: linear()](https://developer.chrome.com/docs/css-ui/css-linear-easing-function).

CSS применяется к конкретному свойству со своими ограничениями. Кроме того, модель CSS включает fill, направление проигрывания, boundary flags и возможный вход вне `[0,1]`; точное соответствие наших функций указано только на поддерживаемом домене и, для steps, при `before=false`.

## 6. After Effects: самостоятельный пример expression

Для **двух ключей одного числового или векторного свойства** можно использовать выражение со smootherstep. Пример демонстрирует математический перенос; он не является реализованным импортёром Curve System и не проверялся в запущенном After Effects в рамках версии 0.1.

```js
if (numKeys < 2) {
  value;
} else {
  var t0 = key(1).time;
  var t1 = key(2).time;
  var u = Math.max(0, Math.min(1, (time - t0) / (t1 - t0)));
  var eased = u * u * u * (10 + u * (-15 + 6 * u));
  linear(eased, 0, 1, key(1).value, key(2).value);
}
```

Выражение использует только первый и второй ключ и держит крайнее значение за ними. Оно не сохраняет пространственную Bézier-траекторию Position: векторные значения интерполируются непосредственно. Оно также не является drop-in решением для Shape, TextDocument или произвольного набора ключей.

`linear()` здесь допустим, потому что smootherstep находится в `[0,1]`. Для back/elastic, где нужно сохранить overshoot, такой clamp нельзя неявно использовать: вычислять `from + (to - from) * f` с корректными операциями для типа свойства. Базовые методы интерполяции описаны в [официальном справочнике expressions Adobe](https://helpx.adobe.com/after-effects/using/expression-language-reference.html).

Speed Graph — отдельное представление. Для переноса заданной формы скорости в значение нужно интегрировать её, учесть направление и нормировать площадь. Простое назначение графика скорости как easing меняет задачу.

## 7. CSV, кадры и конечная точность

Кнопка CSV выгружает `t,value,velocity,acceleration,jerk`. В пустых ячейках производных нет конечного значения по контракту evaluator. Ноль и пустая ячейка имеют разный смысл. Производные остаются нормализованными.

При экспорте на таймлайн с $N$ промежутками между ключами нужны $N+1$ точек с обоими концами. Это не то же самое, что число отображаемых кадров клипа в полуоткрытом интервале. Для 24/25/30 fps и особенно рациональных timebase вроде 30000/1001 заранее определить правило включения конца.

Ни 241, ни 1000 отсчётов сами по себе не гарантируют нужную ошибку. Среда может добавить интерполяцию между импортированными ключами и изменить получившийся профиль. Для переносимого результата сравнить исходный evaluator и экспортированный результат в независимой плотной сетке, включая события и окрестности экстремумов. Если важно ускорение, проверять его отдельно: маленькая ошибка значений ещё не означает маленькую ошибку производных.

## 8. JSON для агента

Лаборатория копирует **описание выбора**: id, параметры, длительность просмотра и выходную политику. [Схема](../catalog/selection.schema.json) проверяет структуру; допустимость `id` и диапазоны параметров дополнительно проверяет ядро. JSON не содержит исполняемую строку формулы.

Передавая выбор другому агенту, добавить задачу и целевую среду:

> Анимируй X камеры от 0 до 400 px за 2 секунды. Используй `smootherstep` из этой версии Curve System. Нулевые скорость и ускорение на концах обязательны, выход за диапазон запрещён. Сохрани редактируемые ключи; если точный перенос невозможен, сообщи представление и измеренную ошибку.

Для stateful-follow запрос должен включать текущие положение/скорость, изменяющуюся цель, единицы и шаг времени. Одного названия easing для него недостаточно. См. [скилл](../skills/curve-system/SKILL.md).

## 9. Воспроизводимость и текущие ограничения

`npm run build:atlas` пересоздаёт статические изображения и реестр из evaluator. `npm test` проверяет математические свойства. `node scripts/render-atlas.mjs --check` проверяет, что сохранённые артефакты совпадают с генерацией.

Не реализованы автоматические импорты/экспорты AE и Blender, drag-редактор handles, составной таймлайн, PCHIP, адаптивный LUT и прерываемая пружина. Их описание в исследованиях служит планом работы, а не обещанием доступной функции.
