# Дорожная карта

Этапы задают порядок и критерии готовности, а не календарные обещания. Статус зафиксирован на 24 ноября 2026.

## 0.1 · Основа — реализовано

- 40 пресетов из 16 семейств; метаданные и строгий evaluator.
- Значение, первые три производные и события разрыва.
- 43 программно построенных SVG: 40 карточек, галерея, обложка и четыре графика smootherstep.
- Curve Lab: выбор, параметры, сравнение, курсор, воспроизведение, JSON/CSV и ограниченный CSS-export.
- Два отдельных исследовательских эссе и реестр внешних проектов.
- Математический справочник, инструкция по применению, архитектура и агентский скилл.

Это reference prototype. Отдельный отчёт внешнего Deep Research не импортирован; пакет не опубликован в npm, GitHub Pages не включён.

## 0.2 · Составные кривые и редактирование — предложено

Добавить multi-segment Bézier/Hermite, контроль касательных и длительности каждого сегмента. Отдельно — монотонную интерполяцию PCHIP и линейные/hold участки.

**Критерий готовности:** сохраняемый JSON восстанавливает форму; смена длительности сегмента правильно меняет наклоны в физических единицах; редактор показывает нарушения C¹/C² на стыках; история изменений и undo не теряют параметры.

Нужны drag-handles с клавиатурной альтернативой, сравнение двух произвольных конфигураций, избранное и именованные presets. UI должен показывать различие между «форма изменилась» и «время растянулось».

## 0.3 · Перенос и измеряемая ошибка — предложено

Реализовать адаптивный sampling и CSS `linear()`. Начать с одного редакторского адаптера, выбранного по реальному проекту: например, Blender F-Curves или After Effects expressions/keyframes. GLSL/WebGL добавить после общего контракта float precision и тестовых векторов.

**Критерий готовности:** экспорт включает representation, исходную кривую, погрешность, параметры упрощения и endpoint policy. Round-trip сравнение обнаруживает ошибки времени, overshoot и интерполяции. Пользователь знает, что остаётся редактируемым.

## 0.4 · Stateful motion — предложено

Добавить пружины и сглаживание, которые сохраняют положение/скорость при смене цели. Развести `evaluate(t)` и `advance(state, target, deltaTime)`; задать физические единицы, критерий покоя, max-delta и поведение после паузы.

**Критерий готовности:** сравнение при разных последовательностях deltaTime, прерывания без незапрошенного скачка значения/скорости, воспроизводимый offline-render. «Выглядит как пружина» не заменяет соответствие заявленной модели.

## 0.5 · Отраслевые расширения — предложено

| Направление | Что добавить | Что должно доказать испытание |
|---|---|---|
| Аудио | Огибающие, equal-power/correlated fades, log/dB mapping | Нет необоснованного смешения мощности, амплитуды и громкости |
| Видеомонтаж | Time remap, скорость клипа, piecewise ramps | Корректная интеграция скорости, timebase и диапазон источника |
| Камеры | Параметризация длиной дуги, положение/вращение | Заданная скорость по пути и корректная интерполяция ориентации |
| Процедурная графика | Impulse, pulse, smooth min/max, циклические формы | Чёткое различие bounded easing и общего сигнала |
| Управление движением | Обёртка над trajectory generator | Соблюдение заданных p/v/a/j ограничений в конкретной модели |
| Агентские инструменты | Локальный API/MCP для поиска, сравнения и экспорта | Агент не путает статус функции, модель и представление |

## Публикация и сопровождение

До объявления проекта общедоступной библиотекой для переиспользования владелец выбирает общую лицензию. Перед vendoring сторонних компонентов фиксируются LICENSE, notices и точный commit. Публикация npm и GitHub Pages должна следовать за стабильным API и проверенным пользовательским запуском.

Самая полезная ближайшая работа — испытать несколько конкретных переходов в реальном монтажном проекте и измерить, какие сведения теряются между редактором, человеком и агентом. Это поможет выбрать первый адаптер по реальной потребности.
