# Происхождение, источники и лицензии

## Материалы Curve System

Reference implementation, SVG-рисунки, интерфейс лаборатории, тексты и агентские инструкции этой первой версии подготовлены для Curve System. Сторонние библиотеки, картинки и большие фрагменты чужих публикаций в исходники не включены. Формулы общеизвестных семейств реализованы самостоятельно; ссылки объясняют математическое/историческое происхождение.

Общая лицензия проекта пока не выбрана владельцем. `UNLICENSED` в package.json означает отсутствие выбранного разрешения на распространение этого пакета, а не утверждение, что формулы математики могут быть закрыты сами по себе. Публичная видимость репозитория не заменяет лицензионного разрешения. [GitHub: licensing a repository](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository).

## Источники и внешние кандидаты

Проверенные условия и зафиксированные снимки перечислены в [research/resources.md](research/resources.md). Это список для сравнения и планирования, а не список уже включённых зависимостей.

Для будущего включения внешнего компонента записать:

| Поле | Что сохранить |
|---|---|
| Origin | Репозиторий, конкретный путь и URL |
| Revision | Commit или tag, дата проверки |
| License | SPDX, если применим, и фактический текст LICENSE |
| Attribution | Copyright notice и дополнительные notices |
| Scope | Какие файлы, данные, шрифты или изображения перенесены |
| Changes | Что изменено и как это влияет на исходную реализацию |
| Compatibility | Решение о совместимости с выбранной лицензией Curve System |

У root LICENSE, отдельных helper-функций, демонстрационного сайта и ресурсов могут быть разные условия. Бесплатность продукта не означает MIT или отсутствие ограничений. Если источник недоступен, помечать условия как не проверенные и откладывать копирование соответствующих файлов.

## Графики

`assets/*.svg` и `assets/curves/*.svg` создаёт [генератор](scripts/render-atlas.mjs) из [evaluator](src/curves.mjs). Они не являются скриншотами easings.net, Adobe, GSAP или других сторонних сайтов. Для пересоздания выполнить `npm run build:atlas`.
