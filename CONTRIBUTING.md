# Как развивать Curve System

Полезный вклад — это новая проверенная кривая, точный адаптер, воспроизводимый эксперимент, исправление математики или источник, который меняет инженерное решение.

## Добавить кривую

1. Найти первоисточник и объяснить, чем семейство отличается от уже имеющихся.
2. Задать стабильный `id`, область определения, параметры, выходной диапазон, граничные значения и семантику окончания.
3. Реализовать вычисление в `src/curves.mjs`, добавить метаданные и производные. Не скрывать разрывы и сингулярности.
4. Написать проверку независимого свойства: например, равенство интеграла скорости перемещению, точные граничные условия или известный результат для Bézier.
5. Запустить `npm run build:atlas`, затем `npm run check`. Проверить SVG и демо глазами.
6. Обновить `CHANGELOG.md`. Указать происхождение, ограничения и точность аппроксимации.

## Добавить адаптер

Сначала определить, что он переносит: аналитическую функцию, контрольные точки, ключевые кадры, таблицу отсчётов или только изображение. Для экспорта через samples сообщать ошибку аппроксимации; число samples само по себе точность не гарантирует.

Сопоставлять значения в одинаковые моменты времени. Проверять overshoot, ключи на границе кадров, отрицательные/нулевые длительности и поведение между последним ключом и концом клипа. Пользователь должен знать, что осталось редактируемым.

## Добавить источник

Указать автора/проект, прямую ссылку, дату проверки, что именно подтверждается и что остаётся непроверенным. Сведения об активности и лицензии относятся к проверенной версии. Не заменять сравнение числом звёзд.

Не добавлять чужой код без установленного разрешения. Лицензия документации, кода, демо и ресурсов одного проекта может различаться.

## Локальная проверка

```sh
npm test
npm run build:atlas
npm run check:docs
python3 -m http.server 8000
```

Открыть `http://localhost:8000/examples/playground.html`. Для демо достаточно браузера и сервера статических файлов. Установка npm-пакетов не требуется.
